## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Installation & Execution

1. Clone the repository.
2. Once cloned navigate to the project directory and open with VScode.
3. Install the node modules on the terminal with this command:
  npm install
  note: make sure you're in the project directory on the terminal
4. Run the project with this command:
  npm run dev
  Copy the local link and paste on your favorite browser and Voila, you've run the project.
